Installation guide

Windows

Installing on Windows

  1. Download RiffPilot_Setup_1.0.0.exe above
  2. Double-click the installer to run it
  3. If Windows SmartScreen appears, click “More info”
  4. Then click “Run anyway”
  5. Follow the setup wizard and launch Riff Pilot
The SmartScreen warning appears because the app is new and not yet signed with a paid certificate. It is safe to install.

macOS

Installing on Mac

  1. Download RiffPilot_1.0.0_macOS.dmg above
  2. Open the DMG and drag Riff Pilot into Applications
  3. Open Riff Pilot from Applications — a warning will appear
  4. Open System Settings → Privacy & Security
  5. Scroll down and click “Open Anyway” next to the Riff Pilot message
  6. Click “Open” in the confirmation dialog
macOS Gatekeeper blocks apps from unidentified developers. You only need to do this once — it will open normally after that.
